# Citrosis Android

The Android edition of [Citrosis](https://github.com/GRID0-net/GRID0-citron), based
on [Lemon Project](https://github.com/Ghael-V/Lemon-Project) with Citrosis RAM safeguards, GRID0+ networking and Splatoon 3 fixes.

Lemon was chosen due to its great optimization efforts for switch emulation on android, and because its a much better base than citron neo is currently
because of the drastic differences between this branch and the desktop branch, its kept here and not merged.
